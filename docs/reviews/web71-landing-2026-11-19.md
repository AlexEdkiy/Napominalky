# WEB-71 — лендинг по HTML-макету

19 ноября 2026. Ветка `web71-landing`, Codex, самопроверка.
Пользователь поручил разработку и публикацию на корневом домене.

Сохранены композиция, цвета, SVG-иллюстрации интерфейса, фея и Roboto из макета.
HTML очищен от редактора/React/bundler. Добавлены viewport, мобильное меню,
адаптивность, рабочий пример покупок с клавиатурным управлением, ссылки входа,
регистрации и APK. Гость/офлайн явно относятся к Android; на iPhone доступен кабинет.
Декоративные карточки сдвинуты, чтобы не закрывать название и элементы демо.
Все ресурсы локальные, трекеры отсутствуют. Canonical — www, title/description,
OpenGraph, favicon, robots, sitemap; отдельная информационная страница хранения
данных вместо неработающей ссылки. Это описание поведения, не выдуманная юридическая политика.

APK — существующий MOB-77 **1.0.8 (52)**, 121111666 байт; сборка проверяет SHA-256
`2e5d4a79c26a883bf6f8687bc8eab4e002bb8c94af2aafbb393063801d89f69d`.
Он копируется в публичную сборку вне Git и скачивается с нашего домена.
APK не пересобирался, не устанавливался на физический телефон в этой задаче.

Проверены Chromium 1440/390/320/768: меню, keyboard/pointer demo, отсутствие
горизонтального overflow/ошибок JS/внешних загрузок, якоря, изображение, HEAD APK,
страница данных и 404. Скриншоты desktop/mobile просмотрены; это эмуляция viewport.
Артефакты: `Napominalky-artifacts/web71/browser-final/`.

Публикация подготовлена отдельным `deploy/landing/publish_vps.py`:
manifest, root-owned immutable release, тестовый nginx/loopback 18090,
проверка APK Range, замена только landing на 18089, сохранение предыдущего
контейнера и автоматический откат при ошибке. API и данные не изменяются.
Временный migration sudo удалён ранее; для переключения нужна одна административная
команда владельца. Повторное согласие на публикацию не запрашивается.

Статус: исходники готовы; CI, итоговый артефакт и server/public smoke фиксируются ниже.

## Исправление запуска publisher

Первый запуск владельцем остановился на preflight `docker image inspect`:
`No such image: nginx:1.30.7-alpine@sha256:bef154…`. До копирования артефакта и
переключения контейнера выполнение не дошло. Чтение маркеров подтвердило
`ops17-bootstrap` у лендинга и прежний `r9e7ac28-ops18` у кабинета.

Причина: перенос OPS-18 через `docker save/load` по ID сохранил образ, но не ссылку
с именем репозитория. ID подтверждён OCI-индексом перенесённого архива и release.json.
Publisher и Compose используют точный локальный ID `sha256:bef154735288bc38d99fac41ae63730684bcc661503673a04a0f9bc526ba8598`,
скачивание отключено. До изменений production publisher проверяет совпадение ID.
Самопроверка реальных `start()`/`smoke()` в отдельной локальной сети прошла:
nginx -t, HTML/ресурсы/404/APK Range и manifest. Временные контейнер и сеть удалены.
Compose config с обязательными переменными и синтаксис Python проверены.
Результат: `Napominalky-artifacts/web71/publisher-imagefix-smoke.json`.

На VPS атомарно заменён только `/home/devops/napominalky-deploy/web71/publish_vps.py`:
SHA-256 `288cb1ad9dba5b4a6731110ac53e0b665c075249d08034206a08b916b2c7b4d7`.
Исходный tar сохраняет прежнюю копию publisher: повторно не распаковывать его поверх
исправления. 14 файлов артефакта и source e53978c неизменны. Следующий шаг — повторить
ту же sudo-команду, затем проверить публичный сайт; WEB-71 пока in_progress.

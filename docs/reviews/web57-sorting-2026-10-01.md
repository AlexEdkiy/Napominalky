# WEB-57 — порядок задач и ближайших напоминаний

Ветка: `manage-2026-09-30`, worktree `Napominalky-control`.
Самопроверка автора; независимое ревью не выполнялось.

## Изменения

- На показанной пользователем странице «Задачи и списки» выполненные строки
  располагаются после активных. Это первичное правило при любой сортировке колонок
  в обоих направлениях. Внутри групп сохраняется выбранный порядок, а без сортировки —
  порядок API. Отметка/снятие выполнения и дозагрузка обновляют положение строки.
- По явному ответу пользователя «Показывать только предстоящие» оба блока ближайших
  напоминаний (Обзор и таблица) исключают просроченные и выполненные, сортируют
  по дате/времени от ближайшего и затем показывают первые пять.
- События сегодняшнего дня, время которых ещё не наступило, также видны в Обзоре:
  прежде они попадали только в счётчик. Просроченные доступны в разделе «Напоминания».
- Обработаны часовые пояса и некорректные даты. Список напоминаний загружается со всех
  pending-страниц: 50 старых записей не скрывают будущее событие на следующей странице.
  При ошибке дозагрузки выводится ошибка, а не неполный результат сортировки.

API, backend, схема и нативное приложение не меняются. Сортировка задач действует
на загруженный набор (пагинация таблицы сохранена). API пока не фильтрует напоминания
по датам, поэтому количество запросов блока зависит от числа pending-страниц.

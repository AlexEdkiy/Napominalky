## Подтверждённые факты

Пользователь сообщил ERR_CONNECTION_TIMED_OUT для lk.napominalky.ru; прежний
jemsoft.ru/napominalki/ тоже недоступен на домашнем интернете без VPN.
Проверка через мобильного оператора и название домашнего провайдера запрошены.

Сервер: TCP 80/443 слушают на всех IPv4/IPv6 адресах; nginx/API/web работают,
restarts=0, CPU контейнеров менее 1%. UFW явно разрешает 80/443; DOCKER-USER пуст;
Fail2ban содержит только jail sshd. HTTPS-запросы напрямую к IP с SNI обоих
доменов проходят с проверкой сертификата и возвращают текущий release marker.
Это проверки с самого сервера, сами по себе они не доказывают внешнюю доступность.

## Подготовленный текст обращения в хостинг — не отправлено

Здравствуйте. Для сервера с публичным IPv4 94.103.15.24 наблюдается региональная
недоступность TCP 443. 18.11.2026 около 18:13 МСК независимые узлы Timeweb
(AS9123), IOT (AS29182) и Selectel (AS50340) не устанавливают соединение,
в то время как Hetzner (AS24940, Германия) получает HTTP 200 и TCP RTT около 12 мс.
Новый и прежний домены недоступны также из домашней сети владельца.
На сервере nginx работает, порт 443 слушает 0.0.0.0, UFW разрешает 80/443,
DOCKER-USER без правил, Fail2ban применяется только к SSH; перегрузки нет.

Просим проверить внешнюю маршрутизацию, фильтрацию/anti-DDoS и ограничения
входящего трафика к данному IP из российских сетей. Если восстановить доступ
на текущем адресе нельзя, сообщите вариант другого IP с возможностью проверки
доступности до переключения, а также условия/стоимость. Результаты измерений —
по ссылкам выше. Самостоятельную смену адреса и перезапуск сервера не запрашиваем.

## Следующий шаг

Получить сведения о хостинге и доступе к панели. Сначала восстановить сетевую
доступность у провайдера либо проверить предложенный дополнительный адрес
из затронутых сетей. До этого не менять A-записи повторно и не откатывать код:
те же TCP-потери затрагивают старый и новый домены.

При необходимости смены IP/прокси составить отдельный план с проверкой
всех связанных сайтов, lk/www, старого jemsoft API для APK, TLS и отката.
Платный заказ и отправка обращения требуют соответствующего указания пользователя.
Восстановление не подтверждено; завершать OPS-18 только после внешних проверок
и проверки на затронутом пользовательском подключении.

# WEB-69 — форма без служебного блока после отправки

Ветка `manage-2026-09-30`. Самопроверка автора, не независимое ревью.
Production пока `rb911942-web68`; новый выпуск готовится.

## Изменение

По просьбе пользователя после обычного вызова Telegram форма не показывает
инструкций, подтверждения копирования и кнопок «Открыть приложение» / «Telegram Web».
В заголовке остаётся только контурная иконка; места под обратную связь в теле
заметки/задачи/покупок удалены. Черновик формы и передаваемый текст сохранены.

Отказ резервного clipboard не считается ошибкой отправки, если сформирована
полная ссылка Telegram: она уже содержит текст. Возврат null от window.open
не интерпретируется как неудачный запуск внешнего обработчика. Переходов на Web нет.

Редкие случаи обрабатываются вне формы:

- При превышении ограничения длины URI или исключении window.open, если копирование
  прошло, короткое уведомление предлагает ручную вставку; исчезает через 6 секунд.
- Если при этом недоступен и clipboard, отдельное окно содержит полный выделенный
  текст для ручного копирования. Tab остаётся внутри окна, Escape закрывает только
  это окно и возвращает фокус на иконку; исходная форма остаётся открытой.
- Таймер очищается при закрытии компонента. Изменение текста, отключение кнопки
  и закрытие формы не позволяют показать устаревшее сообщение из pending-копирования.

Механизм передачи текста через tg: и ограничения длины из WEB-68 не менялись.
Backend, схема, зависимости и native APK не меняются. Миграций нет.

## Проверки и выпуск

- Vue typecheck и Vite build прошли (`build.log`).
- 78 файлов / 735 web-тестов прошли (`web-tests.log`); 84 целевых теста (`targeted.log`).
  Проверены порядок copy → tg:, отсутствие блока после обычной отправки, отказ
  резервного clipboard, длинный текст, фокус/Tab/Escape в отдельном окне, скрытие
  уведомления и отсутствие позднего UI после изменения текста/закрытия компонента.
- Chromium: 9 сценариев заметка/задача/покупки × 1365/390/320 px (`browser.json`).
  Подтверждены полный текст в URI и реальном clipboard/Ctrl+V, неизменность HTML формы
  и её высоты после share/событий возврата, отсутствие лишних текстов и ссылок,
  отказ резервного clipboard без появления диалога при пригодном URI.
- Два дополнительных mobile-сценария (`exceptions.json`): длинная заметка сохраняется
  целиком; временное уведомление находится вне формы и исчезает; при недоступном
  буфере отдельное окно позволяет выделить весь текст, Tab удерживает фокус,
  Escape сохраняет основную форму и возвращает фокус на иконку. Скриншоты просмотрены.

Точный SHA, CI и артефакт добавляются перед выпуском.
Синтетические API-фикстуры используются без записи пользовательских данных и отправки
реальных сообщений. Внешний обработчик tg: перехватывается в UI-тестах.
Запуск/чат Windows Telegram в среде недоступен для проверки.
Предыдущий `rb911942-web68` сохраняется для отката.

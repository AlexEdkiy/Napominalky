## Что требуется для продолжения

Две проверки `eas whoami` вернули **Not logged in**; EXPO_TOKEN в окружении не задан.
Клиент уже установлен в npm cache, новую установку/смену SDK делать не требуется.
Пользователю передана команда интерактивного входа в терминале IDE:

```bash
node /home/vselug/.npm/_npx/6bc7bae5c2059953/node_modules/eas-cli/bin/run login
```

Пароль/токен вводятся в терминале Expo, не в переписке. После входа проверить whoami
и project:info, затем из `Napominalky-control/mobile` запустить:

```bash
node /home/vselug/.npm/_npx/6bc7bae5c2059953/node_modules/eas-cli/bin/run build \
  --platform android --profile preview --non-interactive --freeze-credentials --no-wait \
  --message 'OPS-15: mobile sync and logout fixes'
```

Сборку отслеживать до FINISHED, скачать и проверить APK. Если Expo сообщает, что
сохранённой подписи нет, сначала выяснить прежний signing key; не создавать замену
молча, поскольку она может нарушить обновление установленного приложения.

Preview использует действующий backend `r9cb10c6-ops14`: серверное исправление полноты
sync-полей из DEV-24/A ещё требует отдельного backend-выпуска. Получение этого APK
не закрывает этап E (device/crash/two-client/review) всего DEV-24.

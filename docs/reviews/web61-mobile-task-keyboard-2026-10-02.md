# WEB-61 — форма задачи над мобильной клавиатурой

Ветка `manage-2026-09-30`, worktree `Napominalky-control`.
Самопроверка автора; независимое ревью не выполнялось.

По скриншоту пользователя нижние действия формы оказались за экранной клавиатурой.
В WEB-60 проверялись размеры окна, но не уменьшение только visual viewport.
У формы `position:fixed; inset:0` и max-height от layout viewport, поэтому она
не учитывала область, занятую клавиатурой. Такое поведение клавиатуры описано в
[документации Chrome](https://developer.chrome.com/blog/viewport-resize-behavior?hl=en)
и [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport).

Воспроизведение: при layout height 844 px, visual height 360 px и offsetTop 180 px
доступная область заканчивается на y=540 px, а футер старой формы — на y=820 px.
После исправления футер в этом сценарии заканчивается на y=524 px.
События visualViewport эмулируются, геометрию настоящей Vue-формы измеряет Chromium.

## Изменения

- Мобильная форма задачи подписывается на `visualViewport.resize/scroll` и задаёт
  высоту/верхнюю границу overlay по текущей видимой области. Подписки снимаются
  при закрытии, переходе на desktop и размонтировании; без API остаётся CSS fallback.
- Панель использует доступную высоту, прокручивается середина. Отступы над клавиатурой
  уменьшены, безопасная область учитывается. Заголовок и действия остаются снаружи
  прокрутки, overscroll середины не передаётся фоновой странице.
- Поле пункта может сжиматься, между выбором типа и пунктом добавлен отступ.
  На узком экране «Отмена»/«Сохранить» — один ряд; удаление в режиме редактирования
  находится отдельно. Шрифт мобильных полей — 16 px.

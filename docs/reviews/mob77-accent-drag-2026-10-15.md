# MOB-77 — компактные строки и перемещение за плашку

Дата: 2026-10-15. Самопроверка автора: Codex.
Ветка выпуска: `release-mob77`, база `4ea264e` (выпущенный MOB-76).
Исходник APK: `d418d595fbdf21d0dfc005c8ba28891810e87193`, версия 1.0.8. MOB-74 не включена; сервер остаётся `r3bb319c-mob75`.

## Поведение

- Название пункта в одну строку с многоточием, статус/дата/теги под ним.
  Комментарии и свойства снова справа от основного содержимого, как на скриншоте.
- У покупок количество от 1 и кнопка увеличения находятся рядом с названием.
- Иконки с тремя полосками нет. Перетаскивание начинается при захвате левой цветной
  плашки. Область захвата 18 px на всю высоту строки, полоска 4 px расширяется до 8 px
  при нажатии; положение текста не меняется. Отпускание сохраняет порядок.
- Обычная прокрутка за остальную часть строки; чекбокс, название, количество и правые
  кнопки остаются отдельными действиями. Экранный диктор предлагает «Выше/Ниже».
- Завершение без движения не пишет порядок, отмена жеста и обновление данных во время
  перемещения его отменяют. При открытии редакторов захват недоступен.

## Проверки

`npm run typecheck --prefix mobile`, `npm test --prefix mobile -- --runInBand`:
**112 файлов / 1191 тест** прошли. `git diff --check` прошёл.
Новые регрессии проверяют захват, сброс выделения и восстановление прокрутки после
тапа, отключение перемещения при редактировании и отсутствие лишних записей порядка.
Существующие реальные RN-компоненты/хуки → Drizzle/SQLite/outbox проверяют порядок
в задачах/покупках, повторное открытие, скрытые фильтром строки, количество, старые
флаги избранного, push/retry/новую правку во время запроса и pull второго устройства.
Репозитории, SQL-схема и sync API в этой задаче не изменены.

Компонентный стенд использует реальные ItemRow/MetaLine/ReorderableItems/FeedCard,
палитры и Ionicons приложения через React Native Web 0.21.2 / Chromium. Native
Swipeable/SVG/окружение темы заменены адаптерами; данные синтетические. Это не Android E2E.

- Light/dark × 320/360/412: 6 сценариев. Проверены расположение действий справа,
  длинные названия/теги, количество 1/9999, отсутствие горизонтального переполнения
  и звёзд у пунктов. Увеличение количества и звезда главной работают раздельно.
- Mouse/PanResponder на 320/360/412: 3 сценария. Плашка расширяется при захвате,
  возвращается после отпускания; покупка перемещается вверх, свойства/отметка не
  срабатывают, обычный тап по названию после жеста открывает свойства.
- Touch/CDP на 360, light/dark: 2 сценария. Перемещение за плашку и прокрутка
  длинного списка за основную часть строки, без случайных нажатий и перестановок.
- Снимки light 412, dark 320 и активного захвата 360 просмотрены визуально.

# WEB-60 — мобильная кнопка «+» всегда доступна при прокрутке

Ветка `manage-2026-09-30`, worktree `Napominalky-control`.
Самопроверка автора; независимое ревью не выполнялось.

Причина: `LkBottomNav` находилась в обычном потоке после содержимого страницы.
До исправления на странице с 30 задачами при высоте экрана 844 px кнопка была
на y=2202 px в начале и y=1491 px в середине прокрутки — за пределами экрана.

Нижняя мобильная панель закреплена через `position: fixed`, включая круглую «+».
Общая CSS-переменная задаёт высоту панели и резерв внизу содержимого, учитывая
`safe-area-inset-bottom`. Отступ оставляет доступными последние строки и действие
добавления задачи. Слой панели ниже меню создания и диалогов.

## Проверки

- Chromium: 390×844, 320×568, 844×390; длинная таблица сверху/посередине/снизу.
  Координата «+» постоянна, кнопка доступна для нажатия, последняя строка выше неё.
  При 390×844 y=778,5 px во всех трёх положениях прокрутки.
- Главная, задачи, заметки, напоминания и календарь: нижняя панель доступна при
  прокрутке, включая короткую страницу календаря без прокрутки.
- На каждом из трёх мобильных размеров кнопка открывает меню, а его пункты —
  формы заметки, напоминания и списка; меню перекрывает нижнюю панель. Закрытие
  форм и Esc работают. Проверены переход на desktop 1024/1365 px и обратно.
- Браузер использует перехват HTTP с фикстурами; все изменяющие запросы запрещены.
  Ошибок JavaScript и неожиданных запросов нет. Скриншот 390×844 просмотрен автором.
- 30 существующих тестов `LkLayout`/`LkBottomNav` — passed; web typecheck и
  production build `/napominalki/` — passed; `git diff --check` — passed.
- Это проверка мобильного сайта в Chromium, не APK и не физический iPhone/Android.
  Ненулевой safe-area и экранная клавиатура на устройстве отдельно не проверялись.

Доказательства: `/home/vselug/workspace/Napominalky-artifacts/web60/` вне Git.
Изменены только стили web и документация; backend, API и схема БД прежние.

# MOB-75 / MBE-25: избранное и редактирование мобильных списков

Дата: 2026-10-15. Ветка: `manage-2026-09-30`. Автор и самопроверка: Codex.
База: `59f868e`. Решение: [ARCH-7](../architecture/mobile-favorites-order.md).

## Что изменилось

- Звёздочка для целых задач/покупок, их пунктов, заметок и напоминаний: главная,
  разделы, результаты поиска и список выбранного дня календаря. Избранные первыми
  внутри фильтра/раздела; у напоминаний отдельная первая секция. Выполненность,
  фильтр дня, архив и поисковый запрос сохраняют смысл. В поиске сортировка до пагинации.
- `is_favorite` хранится в каждой SQLite профиля и синхронизируется через сервер.
  Старое закрепление заметок сохраняется, оно вторично относительно избранного.
  Звезда — отдельная кнопка, нажатие не открывает запись и не меняет выполнение.
- Количество покупки отображается с 1. «+» в строке увеличивает актуальное значение
  БД атомарно с outbox; быстрые нажатия не теряются, предел 9999 соответствует API.
  Полное редактирование количества остаётся в свойствах пункта.
- Ручка справа позволяет перетаскивать пункт вверх/вниз, с подсветкой места и прокруткой
  у края. Перемещение внутри группы избранного/обычных. Фильтр скрывает выполненные,
  но их слоты не переставляются. Доступны действия экранного диктора выше/ниже.
  Смена данных из sync или открытие свойств отменяют незавершённый жест.
- Один владелец StatusBar по текущему маршруту и теме: тёмные значки на светлом
  редакторе, светлые на тёмном; возврат на главную восстанавливает её стиль.
  Убран двойной iOS safe-area отступ у редактора списка.

## Сохранность и совместимость

Новые колонки default false, прежние записи/UUID/даты/outbox/курсоры не переписываются.
Отсутствие поля в старом push или pull не сбрасывает избранное. REST-редактирование
сайта сохраняет его. Новый push валидирует только значение поля, не урезая legacy payload:
обнаруженная в самопроверке особенность Laravel nested wildcard устранена и покрыта
существующей проверкой всех полей round-trip.

Избранное, количество и позиции пишутся транзакционно со снимками outbox. При ошибке
очереди доменные изменения откатываются. Удалённые/чужие пункты не восстанавливаются.
Запрос чужого UUID теперь получает 422 с откатом всего батча вместо прежней ошибки
уникального индекса 500; данные владельца и непринятая очередь остаются на месте.
LWW остаётся на уровне полной записи. При перестановке >500 записей сервер может
временно показать промежуточный порядок до доставки следующего батча.

## Выпуск и приёмка

Production и установленный APK **1.0.5 (48)** не изменены. Android export — проверка
bundle, не готовый установочный APK. Порядок выпуска: серверная миграция
`2026_10_15_000001_add_favorites.php`, совместимый API, затем новый Expo preview APK.
Не откатывать миграцию колонок после появления избранного: это удалит новые отметки.

В исходной ветке уже есть MOB-74 с обязательным подтверждением email. Для совместного
выпуска остаются рабочий SMTP, DNS отправителя и проверка доставки — см.
[инструкцию](../../deploy/releases/email-verification.md). Прежний релиз сервера
не умеет сохранять избранное, поэтому новый APK раньше сервера не распространяется.

На устройстве проверить светлую/тёмную тему, возврат из редактора, клавиатуру и safe area,
короткий/длинный список на узком экране, перетаскивание у обоих краёв и отмену жеста,
затем второе устройство и работу offline. Сборка APK и эта ручная приёмка ещё впереди.
